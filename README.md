# n8n AI Agents

A collection of Agentic AI workflows built using n8n, OpenAI, Google Workspace, and external APIs to automate real-world tasks.

## Overview

This repository contains AI-powered automation workflows developed using n8n. These workflows demonstrate how Large Language Models (LLMs) can interact with APIs, Google services, and external tools to perform intelligent decision-making, data processing, and task automation.

## Workflows

### 1. Job Suitability Score
- Accepts a job description.
- Extracts required skills, experience, and location.
- Compares them with a candidate's CV.
- Generates an eligibility score and identifies missing skills.

### 2. WeatherStack Gmail AI Agent
- Retrieves weather information using the WeatherStack API.
- Generates a weather summary using OpenAI.
- Sends the report via Gmail automatically.

### 3. MarketStack AI Agent
- Retrieves live stock market data using the MarketStack API.
- Uses OpenAI to generate a natural language summary.
- Demonstrates API integration with AI-powered analysis.
